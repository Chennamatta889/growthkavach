# GrowthKavach

A static, browser-based digital marketing toolkit. No backend, API key or build step is required for this version.

## GitHub Pages

Create a separate public repository named `growthkavach`. Upload `index.html` and `.nojekyll` to the root of `main`. In Settings > Pages, select Deploy from a branch, `main`, `/ (root)`, then Save. Verify the deployment succeeds before using the Pages URL.

## Included tools

SEO checks for pasted HTML, Google search snippet preview, UTM campaign link builder, marketing ROI calculator, keyword idea generator and content planner. Keyword ideas are not live search-volume data. No live URL crawling or AI backend is included yet.

## Future Cloudflare Pages migration

Connect this repository in Cloudflare Pages with no framework/build command and root output directory. Verify deployment before changing DNS or adding a custom domain.
